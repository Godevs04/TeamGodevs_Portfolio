## Local development

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Production build
npm run build

# Preview production build
npm run preview

# SEO readiness checks
npm run seo:audit
```

Create a `.env` from `.env.example` if you need analytics or contact API keys locally.
